# Legacy Code

This directory contains old/experimental code kept for reference.

## mineflayer-gh-bot/

The original GH-series bot built with [mineflayer](https://github.com/PrismarineJS/mineflayer) (JavaScript/Node.js). This was the predecessor to GHBot-Plugin, which is now a PaperMC plugin (Java).

**Status**: Archived, not maintained. See the main [gh-bot/](../gh-bot/) directory for the current implementation.
